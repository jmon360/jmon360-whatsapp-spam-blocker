Overview:
-----------
jmon360-whatsapp-spam-blocker is an AI-powered tool designed to help
manage and secure your WhatsApp Web experience by automatically detecting
and blocking spam and phishing messages. The tool leverages Python, Selenium,
and a keyword-based filtering mechanism to monitor messages in real time,
send automated responses to flagged messages, and block contacts based on
specified country codes.

Motivation & Context:
-----------------------
Phishing and spam messages have been a long-standing concern for messaging
platform users. With WhatsApp being one of the most widely used communication
apps, ensuring user security and reducing unwanted interactions is crucial.
This project was developed as a proof-of-concept to demonstrate how automation
techniques can be used to enhance safety and efficiency in message handling.

Key Features:
--------------
- Real-Time Monitoring: Continuously retrieves the latest messages from
  WhatsApp Web.
- Spam Detection: Uses a keyword-based approach to flag suspicious messages.
- Automated Response: Sends a predefined auto-reply to messages identified as spam.
- Contact Blocking: Analyzes contact details for specific country codes 
  (224, 385, 234, 450, 973, 443, 941, 817, 304, 434) and automatically blocks 
  those contacts.
- Event Logging: Maintains detailed logs of blocked contacts and errors in 
  'blocked_events.log' for auditing and troubleshooting.

Intended Use:
--------------
This tool is intended for educational and personal use. It serves as a learning
resource for developers interested in web automation, cybersecurity, and
message processing. While built for WhatsApp Web, the core concepts can be adapted
to other platforms.
